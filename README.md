# 🌺 কলেজ পাড়া সার্বজনীন দুর্গাপূজা (২৬তম বর্ষ)
> **শ্রী শ্রী শারদীয়া দুর্গাপূজার প্রিমিয়াম ৩ডি ডিজিটাল মণ্ডপ ও সম্পূর্ণ তথ্যসম্ভার**

---

## 🌟 বৈশিষ্ট্যসমূহ (Features)

- 🎭 **সিনেমাটিক ৩ডি পর্দা উন্মোচন (Curtain Opening):** খাঁটি ঐতিহ্যবাহী রাজকীয় কাপড়ের পর্দা, আলোর বিচ্ছুরণ ও ঢাকের বাদ্য।
- 🌺 **পারসিস্টেন্ট ৩ডি মণ্ডপ পরিবেশ:** Three.js / React Three Fiber দ্বারা নির্মিত ভাসমান প্রদীপ, কাশফুল, চাঁদ ও রাতের শারদীয় আকাশ।
- 🗓️ **পূজার সম্পূর্ণ সময় নির্ঘণ্ট (Interactive 3D Timeline):** মহাষষ্ঠী থেকে ত্রয়োদশী প্রতিমা নিরঞ্জন পর্যন্ত প্রতিটি তিথি, সময় ও সন্ধিপূজার নির্ভুল বিবরণ।
- 📜 **৩ডি ডিজিটাল আমন্ত্রণ পত্র:** স্পর্শে উল্টে যাওয়া খাঁটি বাংলা হস্তলিখিত ধাঁচের নিমন্ত্রণ পত্র।
- 👥 **মূল কমিটি সদস্যবৃন্দ:** ৯ জন সম্মানিত সদস্যের ৩ডি গ্লাস কার্ড শোকেস।
- 🎨 **বিজ্ঞপ্তি ও পোস্টার গ্যালারি:** মূল মুদ্রিত নোটিশ ও দেবী প্রতিমার ৩ডি জুম ভিউ।
- 🎵 **ঐতিহ্যের আবহ সংগীত:** খাঁটি ঢাকের লয় ও শঙ্খধ্বনির সমন্বয়।
- 📱 **সম্পূর্ণ রেসপন্সিভ:** স্মার্টফোন, ট্যাবলেট, ল্যাপটপ থেকে 4K আল্ট্রা-ওয়াইড মনিটর পর্যন্ত অপ্টিমাইজড।

---

## 🛠️ প্রযুক্তি স্ট্যাক (Tech Stack)

- **Frontend:** React 19, Vite
- **3D Graphics:** Three.js, @react-three/fiber, @react-three/drei
- **Motion & Interactions:** GSAP, ScrollTrigger, Framer Motion
- **Deployment Platform:** Vercel (Edge Network)

---

## 🚀 লোকাল ডেভেলপমেন্ট (Local Setup)

```bash
# ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev

# প্রোডাকশন বিল্ড তৈরি করুন
npm run build
```

## ☁️ Vercel Deployment

প্রজেক্টটিতে Vercel-এর জন্য `vercel.json` কনফিগারেশন ফাইল যুক্ত রয়েছে (স্বয়ংক্রিয় SPA Rewrites ও High-speed Caching Headers সহ)।
GitHub রিপোজিটরিটি Vercel-এ ইমপোর্ট করলেই ১ ক্লিকে অটোমেটিক ডেপ্লয় হয়ে যাবে।
